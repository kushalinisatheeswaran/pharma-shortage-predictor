# PharmaShortage Predictor

Pharmaceutical Shortage Risk Analysis and Cascade Simulation.

## Overview
PharmaShortage Predictor is a research project designed to investigate whether meaningful drug-shortage risk patterns can be identified using data analysis and machine learning, and to explore hypothetical shortage cascade scenarios.

## Current Project Status
- **Current Phase**: Phase 1 — Project Scope & Definition (In Progress)
- No machine learning models, backend/frontend applications, APIs, databases, or synthetic datasets have been built yet.
- Phase 2 Feasibility Gate (data inspection and schema auditing) must be completed before any model development begins.

## Planned Data Sources
- **FDA Drug Shortages**: Shortage tracking datasets.
- **CMS Medicare Part D**: Aggregated drug prescription and usage data.
- **RxNorm**: Standardized drug terminology and entity mappings.
- **FDA Orange Book**: Therapeutic equivalence evaluations (to be investigated if useful).

## Research & Scientific Disclaimer
- This repository is currently in the initial scope and documentation phase. No empirical results or predictive metrics are claimed at this stage.
- **Medical Disclaimer**: This project is for data analysis and research simulation purposes only. It is **not** a clinical tool and does **not** recommend medication substitutions to patients.
- **Data Boundaries**: CMS Medicare Part D provides aggregated data (not real-time daily/weekly pharmacy demand). RxNorm relationships are structural/semantic mappings and should not be automatically treated as therapeutic substitutions. Demand redistribution in cascade simulations represents hypothetical scenarios.
